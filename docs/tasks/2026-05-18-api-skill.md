### TODO fill category 1: ApplicationService `execute()` body

**Before** (Phase 1.h scaffold)：
```swift
    package func execute(input: Input) async throws -> Output {
        // TODO(/api skill): construct {UC}Service Input from `input` and call service.execute
        fatalError("TODO(/api skill): execute body for {UC}ApplicationService")
    }
```

**After fill (Variant A simple, no UUID generation)**：
```swift
    package func execute(input: Input) async throws -> Output {
        let service = {UC}Service(repository: repository)
        _ = try await service.execute(input: .init(
            {AGG_ID_NAME}: input.{AGG_ID_NAME},
{SERVICE_INPUT_FIELDS_FROM_AS}
            operatorId: input.operatorId
        ))
        return .init({AGG_ID_NAME}: input.{AGG_ID_NAME})
    }
```

`{SERVICE_INPUT_FIELDS_FROM_AS}`: 每 non-ID non-operatorId AS Input field → `            <name>: input.<name>,`

**Variant with server-generated ID**（detected when Service Input has ID field but AS Input doesn't）：
```swift
    package func execute(input: Input) async throws -> Output {
        let {ID_FIELD} = UUID().uuidString
        let service = {UC}Service(repository: repository)
        _ = try await service.execute(input: .init(
            {AGG_ID_NAME}: input.{AGG_ID_NAME},
            {ID_FIELD}: {ID_FIELD},
{OTHER_FIELDS}
            operatorId: input.operatorId
        ))
        return .init({AGG_ID_NAME}: input.{AGG_ID_NAME}, {ID_FIELD}: {ID_FIELD})
    }
```

Detection rule (skill 內 logic)：parse Service.swift Input fields；diff with AS Input fields；若 Service Input 有 field 是 `String` 且名為 `*Id` (suffix `Id`) 且 AS Input 無此 field → server-generated case.

### TODO fill category 2: ApiHandler method AS Input construction

**Before** (Phase 1.i scaffold)：

```swift
        guard case let .json(payload) = input.body else {

        }
        let {aggIdName} = input.path.{aggIdName}

        let asInput: {UC}ApplicationServiceInput = { () -> {UC}ApplicationServiceInput in
            fatalError("TODO(/api skill): construct {UC}ApplicationServiceInput from payload")
        }()
        ...
```

**After fill (Variant A simple — payload fields 1:1 pass)**:
```swift
        let asInput = {UC}ApplicationServiceInput(
            {aggIdName}: {aggIdName},
{PAYLOAD_FIELDS_PASS_THROUGH}

```

**Variant B detection**: 若 payload schema 含 `string` field 用作 Decimal (e.g. `estimatedRevenue: type: string + pattern`) → 加 inline Decimal 解析 + `.invalid<Field>` 422 fallback；或 emit `init(from payload:) throws` extension to AS Input file（同 Phase 1.h scaffold 加 extension block）：

```swift
        guard let estimatedRevenue = Decimal(string: payload.estimatedRevenue) else {
            return .unprocessableContent(.init(body: .json(.init(error: .invalidEstimatedRevenue))))
        }
        let asInput = {UC}ApplicationServiceInput(

{OTHER_FIELDS}
            operatorId: operatorId
        )
```

ISO8601 case 同 (Date.parseIso8601 + catch Iso8601ParsingError → `.invalidDateFormat`)。

### TODO fill category 3: DTO struct toDomain mapper body

**Before** (Phase 1.h scaffold)：
```swift
extension {DomainTypeName} {
    package init(from dto: {DtoTypeName}) throws {
        // TODO(/api skill): map fields with type conversion
        fatalError("TODO(/api skill): struct DTO toDomain for {DomainTypeName}")
    }
}
```

**After fill (simple 1:1 pass)**：
```swift
extension {DomainTypeName} {
    package init(from dto: {DtoTypeName}) throws {
{FIELD_ASSIGNMENTS}
    }
}
```

`{FIELD_ASSIGNMENTS}` per field：
- Simple pass: `        self.<name> = dto.<name>`
- Optional: `        self.<name> = dto.<name>`（type-system 自動處理）
- Decimal: `        guard let parsed = Decimal(string: dto.<name>) else { throw InvalidDecimalStringError(field: "<name>") }\n        self.<name> = parsed`
- Date: `        self.<name> = try Date.parseIso8601(dto.<name>)`（throws Iso8601ParsingError）
- Nested DTO with throwing init: `        self.<name> = try .init(from: dto.<name>)`

### TODO fill category 4: ApiComponents return-nil for unreachable cases

**Before** (Phase 1.i scaffold)：
```swift
        switch error {
        case .checkUserId: self = .checkUserId
        case .invalidEstimatedRevenue: self = .invalidEstimatedRevenue
        case .duplicateCustomizedReportingId: self = .duplicateCustomizedReportingId
        ...
        }
```

**After fill (only modify cases unreachable from current UC)**:
```swift
        switch error {
        case .checkUserId: self = .checkUserId
        case .invalidEstimatedRevenue: self = .invalidEstimatedRevenue
        case .duplicateCustomizedReportingId:
            return nil  // TODO(/api skill): confirm trigger — UUID().uuidString collision 機率極低，結構上永不觸發
        ...
        }
```

**Detection rule**: read `<UC>Service.swift` body for `throw <A>Error.<case>` references；任何 enum case 在所有 known UC Service bodies 都不出現 → mark as unreachable (return nil + TODO comment 引用 `.ai/contexts/<Ctx>/<A>/api.md` 的 reachability 規則).

**v1 simplification**: 只處理本次 invoke 的 UC 對應的 cases；不 retroactively review 所有 cases (defer v2 manual prune)。

## 已知限制

1. **v1 只 fill write UCs** (read UC defer v2 / `/api-query` separate skill)
2. **v1 不 emit Variant B `init(from payload:)` extension** — Variant B parsing inline 在 ApiHandler method (Phase 1.h scaffold 無此 extension)；future v2 / Phase 1.j 加 extension 後 skill 再 emit
3. **v1 不 modify openapi.yaml** — drift cases → exit 3 + remediation hint (D18)
4. **v1 不處理 multipart UC** — defer
5. **v1 不處理 cross-aggregate `mapToApiError`** — Quotation-style 多 branch defer
6. **v1 server-generated ID 偵測**只 cover trivial case (`*Id` String suffix)；複雜 case (`reportId` ↔ `customizedReportingId` rename per OC) defer v2
7. **v1 ApiComponents return-nil detection** 只 process 本 UC 對應 cases；retroactive review of all cases defer
8. **v1 不 retro-fix older scaffolds** — 若 Phase 1.h+1.i ship 後又改 spec，skill 可能 see legacy scaffold shape；defer migration support
9. **Idempotent re-run** = skip already-filled，不 force-overwrite (use `--force` v2 候選)
10. **AS Input field name ≡ payload field name 假設** — divergence (e.g. `customizedReportingId` vs `reportId`) → exit 3 OR manual config
11. **Plugin 連動信任 (Phase 1.g/1.h/1.i 沿用)** — `Operations.X.*` + `Components.Schemas.*` 假設 plugin 已正確 emit
